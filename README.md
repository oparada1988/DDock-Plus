# DDock-Plus

Enhanced Dock experience for GNOME Shell featuring macOS dock zoom, window minimization, and custom folder stacks with assignable icons.

## Features

- Dock enhancement for GNOME Shell 45+
- macOS style dock zoom & animation effects
- Dynamic window minimization & preview integration
- Custom Folder Stack with custom icon selection (presets or custom image files)

## Installation

```bash
make install
```
